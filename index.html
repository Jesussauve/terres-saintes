LE PROJET

Terres Saintes

Un atlas biblique historique destiné à explorer les lieux, les territoires, les milieux naturels et les itinéraires mentionnés dans la Bible catholique.

Primauté de l’Écriture. Le texte biblique est la source première pour les événements qu’il rapporte. Les sources historiques, traditionnelles et archéologiques éclairent le contexte ; elles sont présentées séparément et ne remplacent pas le texte biblique.

Précaution historique. Les tracés et territoires peuvent être indicatifs lorsque la Bible ne donne pas un itinéraire détaillé ou lorsque les identifications géographiques sont discutées. Les incertitudes sont signalées dans les fiches.

Gratuité. Le site est conçu sans compte, publicité ni abonnement. Les fonds cartographiques sont fournis par des services tiers soumis à leurs propres conditions d'utilisation et limites de capacité.
